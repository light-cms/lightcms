Це дуже дорого коштує для завантаження сторінки. Іноді сторінка не завантажується з кешу, вона знаходить дані кілька разів, і кожен запит використовує багато потужностей, які викидають кілограми CO2. Кажуть, що 2-4% викидів co2 надходять з Інтернету.

Як і авіаційна індустрія, мережа може завдати шкоди планеті. Розкладка, яку ви вибираєте, показує наскільки вам важлива земля. Екологічний спосіб обмінюватися інформацією - це статичний генератор сайтів, який одночасно будує ваш сайт, а потім виправляє його від CDN.

## Чому Статичні викиди

Щоб дати реактивний ефект сайтів, зазвичай виконують роботу візуалізацій щоразу, коли хтось взаємодіє: вони виконують код у базі даних і відсилають повну сторінку з сервера. Сервер повинен залишатися в мережі весь час, навіть якщо ніхто не завітає.

- Один раз будується статичний сайт. Завершений HTML скопійовано до CDN вузлів по всьому світу. Подається з кешу:

- Для кожного запиту не потрібно обчислювати. Використання побудованого файлу використовує дуже мало енергії у порівнянні з рендерингом сторінки у польоті.

- Немає завжди на базі даних. Немає серверів та баз даних весь час виконується. Статичним сайтам не потрібен сервер для роботи 24/7. Жодного запиту на базу даних не роблять, що призводить до меншої кількості викидів вуглецю.

- Кеш за замовчуванням. Прохання для кеша краю не може передавати електроенергію поза межами сподівання мережі.

- Маленькі зарплатні. HTML, зроблений з Markdown є крихітним. На клієнт не відправляється важкий JavaScript або жирний CSS. Клієнт завжди отримує файл, тому завантажується швидше.

You all may have heard the study [milliseconds make millions](https://www.deloitte.com/ie/en/services/consulting/research/milliseconds-make-millions.html)

Ефект пульсації: Стійкість

Проект Hugo або Astro Starlight, зроблений в 2016 році, все ще може бути. Виглядають у 2036 році тому, що вміст є простим Markdown (а це не потребує часового часу. Весь ланцюг інструментів є джерелом і vendor<unk> neutral і вихід - це просто папки і файли.

Створення вашого вмісту як Markdown в Git довговічний і заощаджує час.

Як виокремлювати ваші сайти викидів карбонів

Ви не можете поліпшити те, що ви робите, якщо ви не вимірюєте нього:

- [Калькулятор вуглецю на вебсайт](https://www.websitecarbon.com/) - оцінює грами викиду CO2 на сторінку і порівнює ваш сайт з середніми.

- Еко - оцінює досвід сторінки, доступність, оцінка зеленого хостингу та викидів вуглецю.

- Зелений кадр - імітує сценарії користувача та багатокрокову взаємодію для вимірювання споживання вуглецю та енергоспоживання.

- WebPage Test - забезпечує глибоку діагностику продуктивності поряд з оцінками споживання вуглецю, а також базові веб-сайтні підсумки.

- Green Web Checker - перевіряє, чи працює інфраструктура доменів, що розміщуються на відновлюваній енергії.

- Real‑user metrics & Core Web Vitals – metrics like Largest contentful Paint (LCP) and total transfer of initial bundle downloaded by any new user on every visit.

Як будувати зелену мережу

1. **Знижувати статично з CDN** - спосіб зменшити енергію для вмісту сайтів.

2. Статичні сайти збудовані один раз. Потім сервіс CDN зробив його найбільш екологічним шляхом побудови веб-сайту.

3. корабель-JavaScript. Кожен кілобайт повинен бути прочитаний, проаналізований, виконаний і збережений на батареї та пропускній спроможності.

4. Cache images. Медіа - це найбільша частина сторінки, щоб використовувати її через CDN та використовувати сучасні формати, такі як WebP.
