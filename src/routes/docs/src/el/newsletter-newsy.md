Φτάνοντας το κοινό σας άμεσα μετά την δημοσίευση νέου περιεχομένου είναι από τους πιο αποτελεσματικούς τρόπους για να οικοδομήσουμε μια πιστή και αφοσιωμένη βάση ανάγνωσης. Yet the conventional way of running a newsletter has grown unnecessarily clunky and costly.

[LightCMS](https://www.lightcms.me) υιοθετεί μια σύγχρονη, φιλική προς τους προγραμματιστές προσέγγιση: **Git καθοδηγείται ενημερωτικά δελτία** που τροφοδοτείται από [Newsy](https://newsy.lightcms.me/). για περισσότερες λεπτομέρειες, ελέγξτε το [repo](https://github.com/light-cms/newsy).

## Η Προσέγγιση Git Driven

Η φιλοσοφία [Newsy](https://newsy.lightcms.me) είναι απλή: **Τα προβλήματά σας στο GitHub χρησιμεύουν ως μοναδική πηγή αλήθειας για το ενημερωτικό δελτίο σας.**

[Newsy](https://newsy.lightcms.me) είναι μια υπηρεσία ανοιχτού κώδικα, αυτοματοποιημένη newsletter που παρακολουθεί το αποθετήριο GitHub:

Newsy watches repository events και έξυπνα ανιχνεύει τα πρόσφατα δημιουργημένα αρχεία περιεχομένου στο διαμορφωμένο repo. Φροντίζει όλα τα άλλα από μόνη της. Μάθετε περισσότερα και εξερευνήστε την ιστοσελίδα [Newsy](https://newsy.lightcms.me).
