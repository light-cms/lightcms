Κοστίζει πολλά για να φορτώσετε μια σελίδα. Μερικές φορές μια σελίδα αποτυγχάνει να φορτώσει από την κρύπτη η βάση δεδομένων είναι χτύπημα πολλές φορές και κάθε ερώτημα χρησιμοποιεί πολλή ενέργεια που εκπέμπει κιλά CO2. Λέγεται ότι 2-4% των εκπομπών του κα2 προέρχονται από το διαδίκτυο.

Όπως και η αεροπορική βιομηχανία, ο ιστός μπορεί να βλάψει τον πλανήτη. Η διάταξη που επιλέγετε σας επιτρέπει να δείξετε πόσο ενδιαφέρεστε για τη Γη. Ο φιλικός προς το περιβάλλον τρόπος για να μοιραστείτε πληροφορίες είναι μια στατική γεννήτρια site που χτίζει το site σας μια φορά και στη συνέχεια εξυπηρετεί από ένα CDN.

## Γιατί Στατικές Τοποθεσίες Εκτάκτου Άνθρακα

Για να δώσετε ένα αντιδραστικό εφέ οι ιστοσελίδες εκτελούν γενικά την εργασία αποτύπωσης κάθε φορά που κάποιος αλληλεπιδράσεις: τρέχουν κώδικα ρωτούν τη βάση δεδομένων και στέλνουν μια πλήρη σελίδα από το διακομιστή. Έτσι, ο διακομιστής πρέπει να παραμείνει σε απευθείας σύνδεση όλη την ώρα, ακόμη και όταν κανείς δεν επισκέπτεται.

- Μια στατική τοποθεσία χτίζει μια φορά. Η ολοκληρωμένη HTML αντιγράφεται σε κόμβους ακμής CDN παγκοσμίως. Σερβίρεται από την κρύπτη:

- Δεν απαιτείται υπολογισμός για κάθε αίτηση. Η εξυπηρέτηση ενός χτισμένου αρχείου χρησιμοποιεί πολύ μικρή ενέργεια σε σύγκριση με την απόδοση μιας σελίδας στη μύγα.

- Όχι πάντα σε βάσεις δεδομένων. Δεν εκτελούνται συνεχώς διακομιστές και βάσεις δεδομένων. Οι στατικοί ιστότοποι δεν χρειάζονται εξυπηρετητή να λειτουργεί 24/7. Δεν υπάρχουν ερωτήματα για τη βάση δεδομένων που να οδηγούν σε λιγότερες εκπομπές άνθρακα.

- Προσωρινή μνήμη από προεπιλογή. Ένα αίτημα που χτυπά μια προσωρινή μνήμη ακμής δεν κινείται ενέργεια πέρα από το λυκίσκο του δικτύου.

- Μικρά ωφέλιμα φορτία. Η HTML που δημιουργήθηκε από Markdown είναι μικρή. Δεν αποστέλλεται βαριά JavaScript ή λίπος CSS στον πελάτη. Ο πελάτης λαμβάνει πάντα το αρχείο έτσι ώστε να φορτώνει πιο γρήγορα.

Μπορείτε όλοι να έχετε ακούσει τη μελέτη [χιλιοστά του δευτερολέπτου κάνει εκατομμύρια](https://www.deloitte.com/ie/en/services/consulting/research/milliseconds-make-millions.html)

Η Επίδραση Κυματισμού: Η Αντοχή Είναι Βιωσιμότητα

Ένα έργο Hugo ή Astro Starlight που έγινε το 2016 μπορεί ακόμα να είναι. Εξυπηρέτησε το 2036 επειδή το περιεχόμενο είναι απλό Markdown, το οποίο παραμένει διαχρονικό. Ολόκληρη η αλυσίδα εργαλείων είναι πηγή και vendor-ουδέτερη και η έξοδος είναι μόνο φάκελοι και αρχεία.

Η κατοχή του περιεχομένου σας ως Markdown στο Git είναι ανθεκτική και εξοικονομεί χρόνο.

Πώς να μετρήσετε τις ιστοσελίδες σας Εκπομπές άνθρακα

Δεν μπορείτε να βελτιώσετε αυτό που κάνετε αν δεν το μετρήσετε:

- [Ιστοσελίδα Υπολογιστής Carbon](https://www.websitecarbon.com/) – υπολογίζει τα γραμμάρια CO2 που εκπέμπονται ανά σελίδα προβολή και συγκρίνει το site σας με το μέσο όρο.

- Eco grader – εκτίμηση της εμπειρίας σελίδας, της προσβασιμότητας, της πράσινης φιλοξενίας και των εκπομπών άνθρακα.

- Πράσινο Πλαίσιο - προσομοιώνει σενάρια χρηστών και πολλαπλών παρεμβάσεων για τη μέτρηση του αποτυπώματος άνθρακα επιπέδου εφαρμογής και της κατανάλωσης ενέργειας.

- WebPage Test – παρέχει σε βάθος διάγνωση απόδοσης παράλληλα με τις εκτιμήσεις αποτυπωμάτων άνθρακα και Core Web Vitals βλάβες.

- Green Web Checker – ελέγχει αν ένας τομέας που φιλοξενεί υποδομές λειτουργεί με ανανεώσιμες πηγές ενέργειας.

- Μετρικές μετρήσεις & Core Web Vitals – μετρήσεις όπως το μεγαλύτερο περιεχόμενο Paint (LCP) και συνολική μεταφορά του αρχικού πακέτου που μεταφορτώθηκε από κάθε νέο χρήστη σε κάθε επίσκεψη.

Πώς να φτιάξετε ένα πιο πράσινο Web

1. **Σερβίρετε στατικά από ένα CDN** - ο τρόπος για να μειώσετε την ενέργεια για ιστοσελίδες περιεχομένου.

2. Οι στατικοί χώροι κατασκευάζονται μία φορά. Στη συνέχεια, σερβίρεται από ένα CDN καθιστώντας το πιο φιλικό προς το περιβάλλον τρόπο για την κατασκευή μιας ιστοσελίδας.

3. JavaScript Αποστολής. Κάθε kilobyte πρέπει να διαβάζονται, αναλύονται, να εκτελούνται και να αποθηκεύονται στην μπαταρία και το εύρος ζώνης των επισκεπτών.

4. Cache images. Τα μέσα μαζικής ενημέρωσης είναι συνήθως το μεγαλύτερο μέρος μιας σελίδας ώστε να το εξυπηρετούν μέσω του CDN και να χρησιμοποιούν σύγχρονες μορφές όπως το WebP.

Όπου Ταιριάζει Το Lightcms

> Το LightCMS λειτουργεί, με ακριβώς αυτούς τους τρόπους:

- Το περιεχόμενο έχει δεσμευτεί ως Markdown στο δικό σας αποθετήριο, δημοσιεύθηκε από μια στατική γεννήτρια site και χρησίμευσε ως μεταγλωτττισμένα αρχεία από το δίκτυο παρόχων φιλοξενίας σας.

- Το CMS εκτελείται μόνο ενώ γράφετε. Καμία βάση δεδομένων παραγωγής δεν εξυπηρετεί τους αναγνώστες επειδή οι αναγνώστες εξυπηρετούνται από ένα CDN.
