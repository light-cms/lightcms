Οι περισσότερες πλατφόρμες περιεχομένου αποθηκεύουν το γράψιμό σας στη βάση δεδομένων τους, το καθιστούν στους διακομιστές τους και σας χρεώνουν για να έχετε πρόσβαση σε αυτό. Όταν η πλατφόρμα κλείνει, αυξάνει τις τιμές, ή αλλάζει τους όρους της, το περιεχόμενό σας συμβαδίζει με αυτό.

Το [LightCMS](https://www.lightcms.me) παίρνει μια διαφορετική θέση: το περιεχόμενό σας ζει στο δικό σας αποθετήριο Git ως απλά αρχεία Markdown . [LightCMS](https://www.lightcms.me) δεν αγγίζει ποτέ τους αναγνώστες σας - τρέχει μόνο ενώ γράφετε.

## Το βασικό πρόβλημα με τις φιλοξενούμενες πλατφόρμες CMS

Όταν δημοσιεύετε σε ένα παραδοσιακό φιλοξενείται CMS, νοικιάζετε χώρο στη βάση δεδομένων κάποιου άλλου. Αυτό ακούγεται καλό μέχρι κάτι να πάει στραβά.

Η πλατφόρμα σκοτώνει τη βαθμίδα του πλάνου σας. Προσθέτουν ένα νέο όριο αποθήκευσης. Μπορούν να αποκτηθούν. Το εργαλείο εισαγωγής διαλείπτει. Ξαφνικά μεταναστεύουν χρόνια περιεχομένου είναι ένα απόγευμα της δουλειάς σας δεν προϋπολογισμού για.

Ακόμα και όταν τίποτα δεν πάει στραβά, το κλείδωμα είναι ήσυχο αλλά πραγματικό. Το περιεχόμενό σας είναι παγιδευμένο σε ιδιόκτητη μορφή πίσω από ένα API. Δεν μπορείτε να εκτελέσετε ένα `grep` στα δικά σας άρθρα. Δεν μπορείτε να αποκρύψετε ένα πρόχειρο από την προηγούμενη έκδοση. Δεν μπορείτε να επιλύσετε μια διένεξη συγχώνευσης σε μια δημοσίευση.

Με [LightCMS](https://www.lightcms.me), το περιεχόμενο έχει δεσμευτεί για το repo σας ως Markdown αρχεία. Αυτό ήταν. Ο εκδοτικός σας αγωγός είναι απλώς μια στατική γεννήτρια τοποθεσίας - Astro, Hugo, Jekyll, Eleventy, Zola, ό, τι ήδη χρησιμοποιείτε. [LightCMS](https://www.lightcms.me) είναι το στρώμα του επεξεργαστή στην κορυφή. Ανταλλάξτε το οποτεδήποτε και το περιεχόμενό σας είναι ανέγγιχτο.

## Τι βασίζεται στην έκδοση Git σημαίνει πραγματικά

Κάθε αποθήκευση είναι μια υποβολή. Κάθε επεξεργασία είναι ελέγξιμη και η έκδοση ελέγχεται. Κάθε ανάρτηση έχει πλήρες ιστορικό που πηγαίνει πίσω στο πρώτο προσχέδιο.

Η συνεργασία λειτουργεί όπως και για τον κώδικα: κλάδοι για προσχέδια, pull requests for review, commit messages as a changelog. Αν είστε ήδη άνετα με το Git, αυτό είναι το νοητικό μοντέλο που έχετε ήδη για όλα τα άλλα στη στοίβα σας.

Το flipside είναι ότι οι αναγνώστες δεν χτύπησαν ποτέ [LightCMS](https://www.lightcms.me). Το περιεχόμενο έχει δεσμευτεί στο αποθετήριό σας, οι διαδρομές του αγωγού κατασκευής (Cloudflare Pages, Netlify, Vercel, GitHub σελίδες), και η έξοδος είναι στατική HTML που σερβίρεται από έναν κόμβο ακμής CDN. Κανένας διακομιστής εφαρμογών δεν βρίσκεται μεταξύ του αναγνώστη και του περιεχομένου.

Αυτό έχει σημασία για την απόδοση - προσωρινά στατικά αρχεία φορτώνουν γρήγορα. Έχει επίσης σημασία για το κόστος. Οι περισσότεροι από αυτούς τους οικοδεσπότες έχουν δωρεάν βαθμίδες που καλύπτουν μια υψηλής κυκλοφορίας προσωπική ιστοσελίδα ή μικρή δημοσίευση χωρίς μηνιαίο λογαριασμό.

## Ο συντάκτης δεν σας κάνει να σκεφτείτε κάτι από αυτό

Η μηχανική Git τρέχει στο παρασκήνιο. Από τον συντάκτη, η εμπειρία είναι απλά γράψιμο.

Ο επεξεργαστής TipTap, γράφει καθαρό Markdown. Μπορείτε να υπαγορεύσετε χρησιμοποιώντας οποιοδήποτε συμβατό API με το Whisper ή Wit.ai αν προτιμάτε φωνή. Το ενσωματωμένο AI copilot, το οποίο λειτουργεί με οποιοδήποτε endpoint συμβατό με το OpenAI, μπορεί να διορθώσει ένα σχέδιο, να καθορίσει μια πρόταση, ή να πάρει εκεί που σταματήσατε.

Όταν χτυπάμε τη δημοσίευση, το LightCMS κάνει υποβολές του αρχείου στη διαδρομή που έχουμε ρυθμίσει και ο αγωγός ανάπτυξής μας αναλαμβάνει. Αν βρίσκεστε στο Cloudflare Pages, η ανάρτηση είναι ζωντανή μέσα σε περίπου ένα λεπτό.

## Τι LightCMS δεν είναι

Δεν είναι μια φιλοξενούμενη πλατφόρμα blogging. Δεν υπάρχει καμία υποδομή που διαχειρίζεται το LightCMS ανάμεσα σε εσάς και τους αναγνώστες σας. Το LightCMS είναι λογισμικό που εκτελείτε ως συγγραφέας και γράφει στα αποθετήρια που κατέχετε.

## Η γωνία βιωσιμότητας

Οι στατικοί χώροι εκπέμπουν σημαντικά λιγότερο CO2 ανά προβολή σελίδας από τα ισοδύναμα που παρέχονται στους διακομιστές. Δεν υπάρχει πάντα σε βάση δεδομένων, χωρίς απόδοση ανά αίτηση, και χωρίς διακομιστή για να κρατήσει ζεστή. Μια προβολή σελίδας που χτυπά μια κρύπτη CDN είναι ως επί το πλείστον απλά ένα hop.

[Research puts a typical static, cached page at around 0.002 grams of CO2 per visit](https://www.websitecarbon.com/) — versus a gram or more for a heavy, server-rendered page. Αυτό το χάσμα ενώνεται σε εκατομμύρια προβολές σελίδων.

Δεν είναι ο κύριος λόγος για να επιλέξετε μια στατική αρχιτεκτονική, αλλά είναι ένα πραγματικό όφελος αν το περιβαλλοντικό κόστος της υποδομής σας έχει σημασία.

## Ποιος είναι για

Το LightCMS είναι μια καλή εφαρμογή εάν:

- Είστε ένας προγραμματιστής που τρέχει ένα blog σε μια στατική γεννήτρια site και θέλετε έναν αξιοπρεπή επεξεργαστή για τον εαυτό σας ή συνεργάτες
- Θέλετε η εγγραφή σας να ξεπεράσει οποιαδήποτε ενιαία πλατφόρμα
- Θέλετε μηδενικό κόστος φιλοξενίας για παράδοση περιεχομένου
- Θέλετε το περιεχόμενό σας σε μορφή που οι πράκτορες κωδικοποίησης AI, τα εργαλεία αναζήτησης και τα προσαρμοσμένα σενάρια μπορούν όλα να διαβαστούν εγγενώς

Δεν είναι καλή εφαρμογή αν χρειάζεστε λειτουργίες σε πραγματικό χρόνο, σύνθετες δομές σχεσιακού περιεχομένου ή μια πλήρως διαχειριζόμενη πλατφόρμα όπου κάποιος άλλος χειρίζεται υποδομές.
