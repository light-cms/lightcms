[LightCMS](https://www.lightcms.me) είναι ένας επεξεργαστής με υποστήριξη Git για στατικούς ιστότοπους. Γράψαμε σε έναν πλούσιο επεξεργαστή, πατήστε δημοσίευση, και το [LightCMS](https://www.lightcms.me) κάνει εκκαθάριση του Markdown στο αποθετήριό μας. Ο αγωγός ανάπτυξής σας — Cloudflare Pages, Netlify, Vercel, GitHub Pages — τον παίρνει από εκεί.

Το περιεχόμενό σας ζει στο δικό σας αποθετήριο Git ως απλά αρχεία Markdown που είναι αναγνώσιμα και μπορούν να αναπτυχθούν από οποιαδήποτε στατική γεννήτρια site που χρησιμοποιείτε ήδη.

## Πώς λειτουργεί

1. Συνδεθείτε με το λογαριασμό σας στο GitHub.
2. Συνδέστε το αποθετήριο που περιέχει το στατικό site σας. Astro, Hugo, SvelteKit, Jekyll, Next.js, Eleventy — οτιδήποτε διαβάζει Markdown.
3. Εγγραφή και επεξεργασία περιεχομένου στον ενσωματωμένο επεξεργαστή. Δημιουργήστε δημοσιεύσεις, επεξεργαστείτε τα υπάρχοντα, ανεβάστε εικόνες και συμπληρώστε τα πεδία της μπροστινής ύλης χωρίς να αγγίξετε ένα τερματικό.
4. Hit δημοσίευση. Το [LightCMS](https://www.lightcms.me) δεσμεύει το περιεχόμενό μας στη διαδρομή που έχουμε ρυθμίσει — για παράδειγμα, το `content/blog/my-post.md` στη ρίζα του αποθετηρίου.
5. Ο αγωγός κατασκευής σας αναπτύσσεται αυτόματα. Η ανάρτηση είναι ζωντανά μέσα σε ένα ή δύο λεπτά, ανάλογα με τον οικοδεσπότη.

Αυτός είναι ο πλήρης βρόχος. [LightCMS](https://www.lightcms.me) τρέχει μόνο ενώ γράφετε. Οι αναγνώστες εξυπηρετούνται από το CDN σας, όχι από το [LightCMS](https://www.lightcms.me).

## Τι υπάρχει στον επεξεργαστή

**TipTap-based rich editor** — writes clean Markdown with front matter. Αυτό που βλέπετε είναι τι έχει δεσμευτεί. Αν έχετε ανοίξει ποτέ ένα αρχείο `.md` και βρείτε μια σούπα ετικετών HTML, αυτή είναι η εναλλακτική λύση.

**AI copilot** — συνδεδεμένο σε οποιοδήποτε API συμβατό με OpenAI. Χρήσιμο όταν μια παράγραφος δεν προσγειώνεται: ζητήστε της να σφίξει τη διατύπωση, να επεκτείνει ένα σημείο, ή να πάρει ένα σχέδιο που εγκατέλειψε τη μέση σκέψη.

**Voice-to-text** - υπαγορεύει απευθείας στον επεξεργαστή χρησιμοποιώντας οποιοδήποτε API συμβατό με Whisper ή Wit.ai. Καλό για να πάρει ένα βρώμικο πρώτο σχέδιο κάτω γρήγορα κατά την πληκτρολόγηση παίρνει τον τρόπο σκέψης.

**Φωτεινά και σκοτεινά θέματα** - διάφορες επιλογές θεμάτων, έτσι ώστε ο επεξεργαστής να είναι άνετος κατά τη διάρκεια μακρύτερων συνεδριών εγγραφής.

**Αυτοματοποίηση Ενημερωτικού Δελτίου** - δημοσιεύστε μια θέση και ειδοποιήστε τους συνδρομητές αυτόματα μέσω [Newsy](/docs/newsletter-newsy). Δεν απαιτείται υπηρεσία ενημερωτικού δελτίου από τρίτους.

## Τι δεν κάνει το [LightCMS](https://www.lightcms.me)

Δεν φιλοξενεί το περιεχόμενό σας ή εξυπηρετεί τους αναγνώστες σας, και αυτό είναι από το σχεδιασμό. Αν έρχεστε από το WordPress ή το Ghost, το CMS που είναι ο οικοδεσπότης είναι αυτό που έχετε συνηθίσει. Εδώ η σχέση είναι διαφορετική: [LightCMS](https://www.lightcms.me) είναι ένα εργαλείο γραφής, όχι υποδομή. Η στατική γεννήτρια τοποθεσίας σας χτίζει την έξοδο, ο πάροχος φιλοξενίας σας το εξυπηρετεί και εσείς έχετε κάθε αρχείο. Η εναλλαγή επεξεργαστών, γεννητριών ή υπολογιστών δεν σημαίνει τη μετεγκατάσταση μιας βάσης δεδομένων.

Δεν αντικαθιστά ούτε την εγκατάσταση ανάπτυξης σας. Λειτουργεί με ό, τι αγωγός έχετε ήδη.
