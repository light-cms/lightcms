Reaching your audience directly after posting new content is among the most effective ways to build a loyal, dedicated reader base. Eppure il modo convenzionale di gestire una newsletter è cresciuto inutilmente clunky e costoso.

[LightCMS](https://www.lightcms.me) adotta invece un approccio moderno e amichevole per gli sviluppatori: le newsletter **guidate da Git** powered by [Newsy](https://newsy.lightcms.me/). per ulteriori dettagli, consulta il repo [](https://github.com/light-cms/newsy).

## L'Approccio Git Guidato: Newsy

La filosofia [Newsy](https://newsy.lightcms.me) è semplice: **I tuoi problemi di GitHub servono come unica fonte di verità per la tua newsletter.**

[Newsy](https://newsy.lightcms.me) è un servizio di newsletter open source e automatizzato che tiene d'occhio il tuo repository GitHub:

Newsy guarda gli eventi del repository e rileva con intelligenza i file di contenuti appena creati nel tuo repo configurato. Si prende cura di tutto il resto da solo. Scopri di più ed esplora il sito [Newsy](https://newsy.lightcms.me).
