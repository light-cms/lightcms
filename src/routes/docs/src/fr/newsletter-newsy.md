Atteindre votre public directement après avoir posté un nouveau contenu est l'un des moyens les plus efficaces pour construire une base de lecteurs loyale et dédiée. Yet the conventional way of running a newsletter has grown unnecessarily clunky and costly.

[LightCMS](https://www.lightcms.me) adopte une approche moderne et conviviale aux développeurs à la place : **newsletters** pilotées par Git et propulsées par [Newsy](https://newsy.lightcms.me/). Pour plus de détails, consultez le dépôt [](https://github.com/light-cms/newsy).

## L’approche Git Driven : Newsy

La philosophie de [Newsy](https://newsy.lightcms.me) est simple : **Vos problèmes GitHub servent de source unique de vérité pour votre newsletter.**

[Newsy](https://newsy.lightcms.me) est un service de newsletter automatisé et open source qui garde un œil sur votre dépôt GitHub :

Newsy surveille les événements du dépôt et détecte intelligemment les nouveaux fichiers de contenu dans votre dépôt configuré. Il s'occupe de tout le reste en soi. En savoir plus et explorer le site [Newsy](https://newsy.lightcms.me).
