Het bereiken van uw publiek direct na het plaatsen van nieuwe inhoud is een van de meest effectieve manieren om een loyale, dedicated reader base te bouwen. Toch is de conventionele manier om een nieuwsbrief uit te voeren gegroeid onnodig onhandig en duur.

[LightCMS](https://www.lightcms.me) neemt in plaats daarvan een moderne, ontwikkelaarvriendelijke aanpak: **Git driven newsletters** aangedreven door [Newsy](https://newsy.lightcms.me/). voor verdere details, bekijk de [repo](https://github.com/light-cms/newsy).

## De Git Driven Approach: Nieuw

De [Nieuw-](https://newsy.lightcms.me) filosofie is duidelijk: **Je GitHub problemen dienen als de enige bron van waarheid voor je nieuwsbrief.**

[Nieuwsy](https://newsy.lightcms.me) is een open source, geautomatiseerde nieuwsbriefservice die een oogje houdt op uw GitHub repository:

Nieuwste horloges gebeurtenissen in de repository en detecteert slim nieuwe inhoudsbestanden in uw geconfigureerde repo. Zij zorgt voor al het andere zelf. Ontdek meer en verken de [Nieuwste Website](https://newsy.lightcms.me).
