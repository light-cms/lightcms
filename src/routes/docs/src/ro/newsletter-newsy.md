Reaching your audience directly after posting new content is among the most effective ways to build a loyal, dedicated reader base. Cu toate acestea, modul convenţional de a administra buletinul informativ a crescut inutil de greoi şi costisitor.

[LightCMS](https://www.lightcms.me) adoptă o abordare modernă, ușor de dezvoltat: **Git driven newsletters** motorizat de [Newsy](https://newsy.lightcms.me/). pentru mai multe detalii, vedeți repo-ul [](https://github.com/light-cms/newsy).

## Abordarea Git Driven - Noutăți

Filozofia [Newsy](https://newsy.lightcms.me) este simplă: **Problemele dvs GitHub servesc drept singura sursă de adevăr pentru buletinul dvs. informativ.**

[Newsy](https://newsy.lightcms.me) este un serviciu de newsletter cu sursă deschisă, automat, care păstrează un ochi pe depozitul dvs GitHub:

Noutăți vizionează evenimentele din depozit și detectează inteligent fișierele nou create în repo-ul configurat. Are grijă de celelalte lucruri de una singură. Află mai multe și explorează site-ul [Newsy](https://newsy.lightcms.me).
