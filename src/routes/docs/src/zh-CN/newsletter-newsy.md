在发布新内容后直接接触您的观众是 最有效的方式之一。建立一个忠实、专心致志的阅读器基础。然而，通用的通讯方式已经增加了 的不必要的混乱和昂贵。

[LightCMS](https://www.lightcms.me) 采取了一种现代的、开发者友好的方式： **Git 驱动的新闻通讯** 由 [Newsy](https://newsy.lightcms.me/) 提供动力。欲了解更多详情，请查阅 [repo](https://github.com/light-cms/newsy)

## 吉特驱动方法：新的方法

The [Newsy](https://newsy.lightcms.me) philosophy is straightforward: **Your GitHub issues serve as the single source of truth for your newsletter.**

[Newsy](https://newsy.lightcms.me) 是一种开源、自动的通讯服务，它能够让您的 GitHub 存储库保持眼光：

Newsy 观看仓库事件并在您配置的仓库中智能检测到新创建的内容文件。它独自照顾其他一切。了解更多信息并探索 [新建网站](https://newsy.lightcms.me)
