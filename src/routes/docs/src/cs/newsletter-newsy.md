Dosažení publika přímo po odeslání nového obsahu je jedním z nejúčinnějších způsobů, jak vytvořit loajální, oddanou čtenářskou základnu. Konvenční způsob provozování newsletteru se však rozrostl zbytečně skromným a nákladným.

[LightCMS](https://www.lightcms.me) místo toho zaujímá moderní, vývojářsky přívětivý přístup: **newslettery** poháněné [Newsy](https://newsy.lightcms.me/). pro další podrobnosti naleznete na [repo](https://github.com/light-cms/newsy).

## Git jízdu: Nepatrná

[Newsy](https://newsy.lightcms.me) filozofie je prostá: **Vaše GitHub problémy slouží jako jediný zdroj pravdy pro váš newsletter.**

[Newsy](https://newsy.lightcms.me) je open source, automatizovaná služba newsletteru, která sleduje váš GitHub repositář:

Newsy sleduje události repositáře a chytrě detekuje nově vytvořené soubory obsahu ve vašem nastaveném repou. Zajišťuje všechno ostatní sama. Zjistěte více a prozkoumejte [Newsy Website](https://newsy.lightcms.me).
