ページを読み込むのに多くの費用がかかります。時には、ページがキャッシュから読み込めないことがあり、データベースが複数回ヒットし、各クエリはCO2の発生キログラムを大量に使用します。 CO2排出量の2~4%はウェブから来ていると言われています。

航空産業のように、ウェブは惑星に損害を与える可能性があります。あなたが選ぶレイアウトは、あなたが地球をどのくらい気にするかを示すことができます。情報を共有するエコフレンドリーな方法は、一度あなたのサイトを構築し、その後、CDNからそれを提供する静的なサイトジェネレータです。

## なぜ静的サイトがカーボンを放出するのか

リアクティブなエフェクトサイトを提供するには、誰かがインタラクションを行うたびにレンダリング作業を実行します。実行されるコードはデータベースに問い合わせ、サーバーからフルページを送信します。そのため、誰も訪問しない場合でも、サーバーは常にオンライン状態にする必要があります。

- 静的サイトは一度構築されます。完成したHTMLは世界中のCDNエッジノードにコピーされます。キャッシュから提供されました:

- 各リクエストに計算は必要ありません。ビルドされたファイルを提供するには、ページをその場でレンダリングするのに比べて、ほとんどエネルギーを消費しません。

- 常にデータベース上にあるわけではありません。サーバーとデータベースが常に実行されることはありません。静的サイトでは、24時間365日動作するサーバーは必要ありません。データベースクエリが行われることはなく、炭素排出が少なくなります。

- デフォルトでキャッシュします。エッジキャッシュに当たるリクエストは、ネットワークホップを超えてエネルギーを移動しません。

- 小型ペイロード。 Markdownから作られたHTMLは小さいです。クライアントに重いJavaScriptや脂肪CSSは送信されません。クライアントは常にファイルを受信するので、読み込みが速くなります。

You all may have heard the study [milliseconds make millions](https://www.deloitte.com/ie/en/services/consulting/research/milliseconds-make-millions.html)

波及効果:耐久性はサステナビリティ

2016年に作られたヒューゴやアストロスターライトのプロジェクトはまだ可能です。 2036年に提供されるコンテンツは時間をかけず、プレーンマークダウンであるため。ツールチェーン全体はソースとベンダーニュートラルで、出力はフォルダーとファイルだけです。

あなたのコンテンツをGitでMarkdownとして所有することは耐久性があり、時間を節約できます。

ウェブサイトの測定方法 二酸化炭素排出量

測定しない場合は、改善することはできません。

- [Website Carbon Calculator](https://www.websitecarbon.com/) – ページビューあたりのCO2排出量を推定し、サイトと平均値を比較します。

- Eco grader – レートのページの経験, アクセシビリティ, グリーンホスティングと炭素排出量の推定値.

- Green Frame:ユーザーシナリオと多段階の相互作用をシミュレートし、アプリケーションレベルの二酸化炭素排出量とエネルギー消費量を測定します。

- WebPage Test – カーボンフットプリントの推定とCore Web Vitalsの故障に加えて、深度のパフォーマンス診断を提供します。

- Green Web Checker – インフラストラクチャをホスティングするドメインが再生可能エネルギーで動作するかどうかをチェックします。

- リアルユーザーのメトリック & Core Web Vitals – 最大のコンテンツペイント(LCP)のようなメトリック、新しいユーザーがダウンロードした初期バンドルの合計転送。

環境に優しいウェブを作る方法

1. **CDN** から静的に役立ちます。これはコンテンツサイトのエネルギーを削減する方法です。

2. 静的サイトは一度構築されます。その後、それをウェブサイトを構築する最もエコフレンドリーな方法にするCDNから提供されました。

3. JavaScriptを発送するすべてのキロバイトは、訪問者のバッテリーと帯域幅に読み取り、解析、実行、保存されなければなりません。

4. Cache images. メディアは通常、ページの最大の部分なので、CDN を介して提供し、WebP のようなモダンな形式を使用します。

LightCMSが適合する場所

> LightCMS は、以下のように機能します。

- コンテンツは自分のリポジトリにMarkdownとしてコミットされています 静的サイトジェネレータによって公開され、ホスティングプロバイダのエッジネットワークからコンパイルされたファイルとして機能しました。

- CMSは書き込み中にのみ実行されます。読者はCDNによって提供されるため、本番データベースは読者に提供されません。
