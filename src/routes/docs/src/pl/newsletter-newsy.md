Docieranie do swoich odbiorców bezpośrednio po dodaniu nowych treści jest jednym z najskuteczniejszych sposobów budowania lojalnej, dedykowanej bazy czytników. Jednak tradycyjny sposób korzystania z newslettera zwiększył się niepotrzebnie i kosztownie.

[LightCMS](https://www.lightcms.me) zamiast tego przyjmuje nowoczesne, przyjazne dla deweloperów podejście: **newslettery** napędzane przez [Newsy](https://newsy.lightcms.me/). aby uzyskać więcej informacji, sprawdź repozytorium [](https://github.com/light-cms/newsy).

## Podejście oparte na Git Driven: Newsy'y

Filozofia [Newsy](https://newsy.lightcms.me) jest prosta: **Twoje problemy z GitHub służą jako pojedyncze źródło prawdy dla Twojego biuletynu.**

[Newsy](https://newsy.lightcms.me) jest otwarto-źródłowym, zautomatyzowanym serwisem newslettera, który śledzi twoje repozytorium GitHub:

Newsy oglądają wydarzenia repozytorium i inteligentnie wykrywa nowo utworzone pliki treści w skonfigurowanym repozytorium. Zajmuje się wszystkim innym samym sobą. Dowiedz się więcej i odkryj stronę [Newsy](https://newsy.lightcms.me).
