Для загрузки страницы требуется много времени. Иногда страницы не загружаются из кэша в базу данных несколько раз, и каждый запрос использует много мощностей, выделяющих килограммы CO2. Говорят, что 2–4% выбросов СО2 поступают из Интернета.

Как и авиакомпании, Интернет может нанести вред планете. Выбор макета позволяет показать, сколько вы заботитесь о Земле. Удобный способ обмена информацией - это статический генератор сайта, который собирает ваш сайт один раз и затем служит его с CDN.

## Почему статические сайты Emit углерода

Чтобы дать реактивный эффект, сайты, как правило, выполняют рендеринг при каждом взаимодействии: они запускают код запрашивают базу данных и отправляют полную страницу с сервера. Так что сервер должен оставаться онлайн все время, даже когда никто не посещает его.

- Статический сайт собирает один раз. Законченный HTML копируется в узлы CDN по всему миру. Подано из кэша:

- Нет вычислений для каждого запроса. Сервирование построенного файла использует очень мало энергии по сравнению с отображением страницы на лету.

- Не всегда на базах данных. Никакие серверы и базы данных не работают всё время. Статические сайты не требуют работы сервера 24/7. Не дается никаких запросов, связанных с базой данных, что приводит к сокращению выбросов углерода.

- Кэш по умолчанию. Запрос, который попадает в кэш границ, не перемещает энергию за пределы сетевого хупа.

- Маленькие полезные нагрузки. HTML, сделанный из Markdown, маленький. Никаких тяжелых JavaScript или жирных CSS не отправляется клиенту. Клиент всегда получает файл, чтобы он загружался быстрее.

You all may have heard the study [milliseconds make millions](https://www.deloitte.com/ie/en/services/consulting/research/milliseconds-make-millions.html)

Эффект Чистильщика: Прочность

Hugo или Astro Starlight, разработанные в 2016 году, все еще может быть. Подано в 2036 году, потому что содержание является простым Markdown, который остается бессрочным. Вся цепочка инструментов является исходным кодом и vendor-нейтральной, а вывод - просто папок и файлов.

Владелец вашего контента как Markdown в Git является прочным и экономит время.

Как измерить ваши веб-сайты выбросов углерода

Вы не можете улучшить то, что делаете, если не измеряете это:

- [Website Carbon Calculator](https://www.websitecarbon.com/) – оценка граммов СО2, испускаемых на страницу и сравнивает ваш сайт со средним.

- Eco grader – страницы тарифов, доступность, зеленый хостинг и оценки выбросов углерода.

- Green Frame - имитирует сценарии пользователей и многошаговые взаимодействия для измерения уровня применения углеродного следа и потребления энергии.

- WebPage Test – обеспечивает глубинную диагностику производительности наряду с оценками углеродного следа и сбоями Core Web Vitals.

- Green Web Checker – проверяет, работает ли инфраструктура хостинга с возобновляемой энергией.

- Real‑user metrics & Core Web Vitals – metrics like Largest contentful Paint (LCP) and total transfer of initial bundle downloaded by any new user on every visit.

Как создать Greener Web

1. **Serve statically from a CDN** – the way to cut energy for content sites.

2. Статические сайты построены один раз. Затем служили из CDN, делая его самым экологически дружественным способом создания веб-сайта.

3. JavaScript. Каждый килобайт должен быть прочитан, обработан, выполнен и храниться на посетителях батареи и пропускной способности.

4. Cache images. Медиа обычно является самой большой частью страницы, так что используйте его через CDN и современные форматы, такие как WebP.
