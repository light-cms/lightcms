Reaching your audience directly after posting new content is among the most effective ways to build a loyal, dedicated reader base. Yet the conventional way of running a newsletter has grown unnecessarily clunky and costly.

[LightCMS](https://www.lightcms.me) придерживается современного удобного для разработчиков подхода: **основанные на Git информационные буквы** на основе [Newsy](https://newsy.lightcms.me/). для получения более подробной информации смотрите [repo](https://github.com/light-cms/newsy).

## The Git Driven Approach: Newsy

Философия [Newsy](https://newsy.lightcms.me) проста: **Ваш GitHub является единственным источником правды для вашего информационного бюллетеня.**

[Newsy](https://newsy.lightcms.me) — это открытый исходный код, автоматизированная служба рассылки, которая следит за вашим репозиторием на GitHub:

Ньюси следит за событиями репозитория и обнаруживает только что созданные файлы контента в настроенном репозитории. Он заботится обо всем остальном самостоятельно. Подробнее об [сайте Ньюси](https://newsy.lightcms.me).
