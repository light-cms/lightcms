Nå dit publikum direkte efter udstationering af nyt indhold er blandt de mest effektive måder at opbygge en loyal, dedikeret læserbase. Alligevel er den konventionelle måde at køre et nyhedsbrev på vokset unødigt klodset og dyrt.

[LightCMS](https://www.lightcms.me) tager en moderne, udviklervenlig tilgang i stedet: **Git drevne nyhedsbreve** drevet af [Newsy](https://newsy.lightcms.me/). for yderligere detaljer, tjek [repo](https://github.com/light-cms/newsy).

## Den Git Driven Metode: Nyhed

[Newsy](https://newsy.lightcms.me) filosofien er ligetil: **Dine GitHub problemer fungerer som den eneste kilde til sandhed for dit nyhedsbrev.**

[Newsy](https://newsy.lightcms.me) er en open source, automatiseret nyhedsbrev, der holder øje med dit GitHub repository:

Nyhed ure repository begivenheder og intelligent registrerer nyligt oprettede indholdsfiler i din konfigurerede repo. Det tager sig af alt andet af sig selv. Find ud af mere og udforsk [Newsy Website](https://newsy.lightcms.me).
