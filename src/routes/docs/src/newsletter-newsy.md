Sending a newsletter when you publish a post is one of the simplest ways to grow an audience. Newsy uses Git as the source of truth so you can automate that step without a separate newsletter platform.

## How Newsy works

- Write and publish posts as Markdown in your repository.
- Newsy watches repository events or a configured issues feed and detects new posts.
- Newsy builds a newsletter from the github issues without any paid subscriptions, and deliverability headaches.

Key points:

- Content stays in your repo, same as news letter.
- You have no headaches of controlling the notification process email deliverability.
- Newsy is open source. See the implementation and examples at [https://github.com/light-cms/newsy](https://github.com/light-cms/newsy)
- Newsy link [newsy.lightcms.me](newsy.lightcms.me)
