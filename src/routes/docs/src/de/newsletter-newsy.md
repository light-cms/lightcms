Ihr Publikum direkt nach dem Posten neuer Inhalte zu erreichen ist eine der effektivsten Möglichkeiten, um eine treue Leserbasis aufzubauen. Yet the conventional way of running a newsletter has grown unnecessarily clunky and costly.

[LightCMS](https://www.lightcms.me) verfolgt stattdessen einen modernen, entwicklerfreundlichen Ansatz: **Git getriebene Newsletter** powered by [Newsy](https://newsy.lightcms.me/). für weitere Details, schauen Sie sich das [Repo](https://github.com/light-cms/newsy) an.

## Der Git Driven Ansatz: Newsy

Die [Newsy](https://newsy.lightcms.me) Philosophie ist einfach: **Ihre GitHub Probleme dienen als einzige Quelle der Wahrheit für Ihren Newsletter.**

[Newsy](https://newsy.lightcms.me) ist ein Open-Source-automatisierter Newsletter-Service, der Ihr GitHub Repository im Auge behält:

Newsy beobachtet Repository-Ereignisse und erkennt intelligent neu erstellte Content-Dateien in Ihrem konfigurierten Repo. Es kümmert sich um alles andere von selbst. Erfahren Sie mehr und erkunden Sie die [Newsy Website](https://newsy.lightcms.me).
